# Новый проект

Проект живёт внутри работы: `work/<работа>/<проект>/`. Подключение Jira и Confluence берётся у работы (`work/<работа>/work.md`, `.mcp.json`), здесь только привязка проекта.

## Правила

- Задавай вопросы по одному.
- Не пиши длинное тире, только обычный "-".
- Существующие папки и файлы не перезаписывай без подтверждения.

## Шаги

### 0. Работа

Найди подключённые работы: `work/*/work.md`.
- Нет ни одной - скажи, что сначала нужно подключить работу, и запусти скилл `setup-work`. Потом вернись сюда.
- Одна - используй её, назови пользователю.
- Несколько - спроси, к какой работе относится проект.

Прочитай `work.md` выбранной работы.

### 1. Название проекта

Спроси: "Как называется новый проект?" Преобразуй в slug: латиница, нижний регистр, `_` вместо пробелов. Покажи путь `work/<работа>/<slug>/` и подтверди.

Если папка уже есть и в ней есть `project.md` - покажи его и спроси, перенастроить или выйти. Если папка есть без `project.md` - это существующий проект, добавь только `project.md`, ничего не перемещая.

### 2. Jira и Confluence

Спроси:
1. Ключ Jira-проекта. По умолчанию `default_jira_project` из `work.md` (например `KPROD`).
2. Пространство Confluence (ключ или ссылка). Можно пропустить.
3. Репозиторий(и) с кодом (путь или URL). Можно пропустить.

Проверь через MCP (инструменты `mcp__jira__*`, `mcp__confluence__*`, ищи через ToolSearch):
- Jira-проект существует - запиши его название.
- Пространство Confluence существует.

Если MCP недоступен - не останавливайся: запиши введённое как есть, пометь `verified: false` и скажи, как проверить позже (запустить `claude` из папки работы или проекта, `/mcp`).

### 3. Файлы проекта

Создай `work/<работа>/<slug>/project.md`:

```markdown
---
type: project
work: <работа>
project: <slug>
jira_project: <ключ>
jira_project_url: <jira_url из work.md>/projects/<ключ>/
confluence_space: <ключ или пусто>
repos:
  - <путь или URL>
verified: <true|false>
created: <YYYY-MM-DD>
---

# <Название проекта>

Задачи: <jira_project_url>
```

Спроси, нужен ли запуск `claude` прямо из папки проекта с Jira/Confluence. Если да - скопируй `work/<работа>/.mcp.json` в `work/<работа>/<slug>/.mcp.json` (там только ссылки на env, токенов нет).

### 4. Итог

Кратко: путь проекта, Jira-проект со ссылкой, пространство Confluence, проверено ли через MCP.
